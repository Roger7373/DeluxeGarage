DELUXE GARAGE — CASH BILL V1.1
================================
This update changes the customer-facing term Invoice to Cash Bill throughout the App and PDF.

Includes:
- Cash Bill A4 heading, Cash Bill No. / Date, Cash Bill buttons and menus
- New Cash Bill serial numbers CB-0001, CB-0002, ...
- PDF filename matches the bill number (e.g. CB-0001.pdf)
- Existing historical INV-0001 numbers remain unchanged so previous records are not renumbered
- Deluxe Garage logo, Hermès Orange/black tint theme, and original A4 layout
- Same Save, Edit, PDF, Print, Share, Customers, Product Catalogue and multi-page behavior
- Same data storage key deluxe_garage_invoice_v1 (IMPORTANT: do not reset it)

UPGRADE EXISTING DELUXE GARAGE GITHUB REPO:
1. Before update, export a JSON backup via Settings in the existing app.
2. Unzip and upload all website files into the existing DeluxeGarage repository root,
   replacing files with the same name. Do NOT upload the ZIP alone.
3. Keep Github Pages main/(root).
4. Open https://roger7373.github.io/DeluxeGarage/ in Safari.
5. If old title remains, close and reopen the home-screen App. Refresh Safari.
6. Check the Cash Bill title in both preview and the exported PDF.

Storage note: Safari and a separately installed home screen App may keep different local data.
Avoid clearing website data or deleting an app with unbacked invoices.

New Cash Bills have CB numbers; existing bills keep their original INV numbers.
This is a brand-specific update and does NOT affect AutoLuxury.
